# ADR 1: Technology Selection for Simple AI Agent

## Status

Accepted

## Context

A simple AI Agent is required for the AI-Augmented Workflow project.
The project should be easy to develop, understand, modify and maintain.

## Decision

Python was selected as the programming language because it is simple,
beginner-friendly and widely used for Artificial Intelligence and Machine
Learning applications.

GitHub was selected for version control and project documentation.

Visual Studio Code was selected as the development environment.

## Technologies

- Python - Programming Language
- Visual Studio Code - Code Editor
- Git - Version Control
- GitHub - Repository and Project Management

## Consequences

### Advantages

- Easy to understand and develop
- Suitable for beginners
- Easy to maintain and modify
- Supports future AI API integration
- GitHub provides version history

### Disadvantages

- Current agent has limited intelligence
- It does not use a real AI model yet
- User interaction is mainly menu-based

## Future Decision

The agent can later be upgraded by integrating an AI API or an
open-source AI model to provide more intelligent responses.

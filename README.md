# Simple AI Agent

## Project Overview

This project is a beginner-friendly AI Agent developed using Python. 
The agent provides a simple menu-based interface for performing basic tasks.

## Features

- Greet the user
- Display the current date
- Perform basic calculations
- Exit the program

## Technologies Used

- Python
- Git
- GitHub
- Visual Studio Code
